## Description
This project implements a Calculator class using Java Object-Oriented Programming.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Average
- Maximum

## Files
- Calculator.java
- CalculatorTest.java
- UML_Diagram
- README.md

## Edge Cases
- Division by zero throws ArithmeticException.
- Modulus by zero throws ArithmeticException.
- Power with exponent 0 returns 1.
- Maximum works with negative numbers.
